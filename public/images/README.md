# Landing page images

These files are referenced by the landing page components and are served
directly from `/images/<name>.png`. Drop the following PNGs into this folder
(keep the exact filenames):

- `hero-celebrate.png`        — Hero section visual
- `features-collage.png`      — Features bento (AI videos card)
- `storyboard-triptych.png`   — "How it works" storyboard
- `social-classroom.png`      — Social proof banner
- `gift-spa.png`              — Marketplace: Serenity Spa Ritual Box
- `gift-chocolates.png`       — Marketplace: Le Cœur Chocolatier Box
- `gift-cards.png`            — Marketplace: Designer Gift Card Suite
- `gift-artisan-box.png`      — Marketplace: The Artisan Collection Box
- `baby-basket.png`           — Marketplace: Baby Basket Card

Until the real files are added, these spots render empty. They previously
lived on Lovable's asset CDN and were removed when the project moved to
Netlify hosting.
